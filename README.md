# DSH-Android

A phone agent for Android, built on [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (dsh). Tell it what you want in one sentence; it operates your phone — files, apps, screen, system settings, automations — with risk-graded approvals.

> Community project. Not affiliated with or endorsed by DeepSeek.
